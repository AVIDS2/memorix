# Governed Graph Evidence Expansion

## Purpose

Issue #175 makes graph context more useful without turning it into an
unbounded graph search. A normal graph-context request first selects a small
lexical/task baseline. Memorix may then add a few *directly related* memories
only when they pass the same evidence governor used by the wider knowledge
system.

```text
task match -> bounded baseline -> one-hop provenance check -> governor -> prompt
```

The result is evidence with a reason, not a second retrieval engine.

## Admission Rules

An extra memory is considered only when it has a direct relationship to a
selected baseline memory:

- a shared or explicitly related entity; or
- a shared commit reference.

It is then evaluated for project scope, freshness, source trust, memory
quality, retention state, and a small token budget. The packet exposes the
accepted evidence, its source observation IDs, relation type, confidence, and
the governor's include/compact decision. Stale or over-budget evidence stays
out of the prompt.

This deliberately does **not** do breadth-first traversal, fabricate graph
relations, or merge a separate RRF ranking with normal retrieval. Private and
targeted observations are filtered by the server before packet construction,
so graph expansion cannot widen a reader's visibility.

## User Effect

`memorix_graph_context` remains an advanced MCP overview tool. Its existing
prompt now has a small `Graph evidence` section when an otherwise missed
memory has direct, governed provenance to the task baseline. Agents can use
that item as a lead and request normal detail only when it is needed.

There is no switch that makes retrieval recursively expand the whole graph;
the bounded default is intentional.

## Contribution Lineage

This work supersedes the useful goal of contributor PR #30, while retaining
its authorship in the issue/PR history. Its earlier implementation used a
parallel BFS and flat reciprocal-rank merge; Memorix instead reuses the
existing evidence governor so graph context, retention, and context budgets
remain one coherent policy.
