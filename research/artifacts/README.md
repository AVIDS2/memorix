# Generated Research Artifacts

This is the only tracked file in `research/artifacts/`.

Docker trial receipts, private evidence sidecars, temporary staging material,
and aggregates are generated locally below this directory and are ignored by
Git. They may contain task-specific provenance and must be materialized into a
separately reviewed submission supplement only through an explicit allowlist.

Do not place credentials, raw model output, personal paths, or manual notes
here. Docker workers keep their deep task workspaces in ephemeral named volumes;
only sanitized exports belong under this boundary.
